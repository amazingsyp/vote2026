# policy-axis-scoring — 공약→성향 축 점수화

후보 공약과 정당 정보를 5축 `AxisVector`(-100..+100)로 변환한다. `data-contract.md` 1절의 축 정의를 따른다.

## 왜 이렇게 하나
일치도 매칭이 의미 있으려면 후보를 사용자와 **같은 좌표계(5축)** 에 놓아야 한다. 점수는 직관이 아니라 공유 루브릭으로 매겨야 정당 간 공정하고, 근거를 남겨야 사용자가 신뢰·검증할 수 있다.

## 축별 채점 루브릭 (-100 ~ +100)
각 축에서 공약 문구의 정책 방향을 보고 점수. 근거 문구를 함께 기록한다.

| 축 | -100 신호 | +100 신호 |
|----|----------|-----------|
| `econ` 경제 | 복지확대·증세·공공일자리·규제강화·임대주택 | 감세·민간성장·규제완화·시장공급·법인유치 |
| `social` 사회·문화 | 소수자보호·다양성·인권·젠더평등·차별금지 | 전통가치·치안강조·가족중심·보수적 교육 |
| `security` 대북·안보 | 남북교류·평화협력·대화 | 강경대응·한미동맹강화·억지력 |
| `env` 환경·개발 | 탄소중립·녹지보전·재생에너지·개발억제 | SOC·재개발·성장우선·규제완화 개발 |
| `gov` 정부역할 | 공공확대·직접공급·국가책임 | 민영화·자율·작은정부·시장위임 |

점수 가이드: 강한 명시 ±70~100, 온건 ±30~60, 약한 언급 ±10~30, 무관/중립 0.

## 워크플로우
1. 후보별 공약 텍스트를 축별로 분류·해석.
2. 각 축에 점수 부여 + 근거 1~2문장. 공약이 정당 통념과 충돌하면 공약 우선.
3. 단체장·교육감 → `axisSource:"pledge"`. 공약 빈약하면 0 근처 + `lowConfidence:true`.
4. 정당 프로파일: 정당의 일반적 정책 노선으로 5축 점수 + `rationale`. 의원 후보는 이를 상속(`axisSource:"party"`).
5. 자체 점검: 같은 루브릭이 모든 정당에 동일 적용됐는지, 한쪽으로 체계적 편향이 없는지.

## 중립성 원칙
- 정당명으로 가점·감점하지 않는다. 공약 문구가 근거.
- 모든 점수는 공약/정책 텍스트로 검증 가능해야 한다. 추정은 lowConfidence로 표시.
- 사용자에게 "이 점수는 공약 기반 추정"임을 프론트에서 밝히도록 근거를 함께 넘긴다.

## 흔한 함정
- 공약 키워드만 보고 과대 점수 — 실현방안·맥락까지 본다.
- 무소속을 정당 통념에 끼워맞추기 — 공약만으로 점수, 없으면 중도+lowConfidence.
- 축 부호 혼동 — `data-contract.md`·`quiz.json`과 부호 규약을 반드시 일치.
